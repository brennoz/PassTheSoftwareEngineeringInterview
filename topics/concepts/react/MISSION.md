# Mission: React + Redux

## Why
Preparing for the BillingCo frontend interview round. The company builds telecoms billing software and expects candidates to discuss and demonstrate commercial React experience — specifically: a feature you personally built, the components involved, and how it interacted with backend APIs. This learning track builds that fluency and vocabulary around a billing domain.

## Success looks like
- Explain React component architecture, hooks, and data flow without hesitation
- Walk through a billing UI (invoice list, invoice detail, payment form) and describe the component tree, state, and API calls
- Describe Redux: store, action, reducer, dispatch — and explain *when* you'd use it vs local state
- Write a `createSlice` with async thunk from memory during an interview

## Constraints
- Interview is imminent — breadth over depth, focus on vocabulary and explanation patterns
- Angular/Vue experience exists but React may be weaker — anchor new concepts to the Spring Boot backend already built (q128)
- No time to build a full app — lessons must be completable quickly

## Out of scope
- React testing (Vitest, Testing Library) — separate topic for later
- Server components / Next.js — out of scope for this prep
- Advanced performance optimisation (memo, useMemo deep dive) — not interview-critical right now
