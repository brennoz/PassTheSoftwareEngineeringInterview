# React Resources

## Knowledge

- [React Official Docs — Describing the UI](https://react.dev/learn/describing-the-ui)
  The authoritative primary source. Covers components, JSX, props, conditional rendering. Use for: any foundational React concept.

- [React Official Docs — Adding Interactivity](https://react.dev/learn/adding-interactivity)
  State, event handlers, render cycle. Use for: useState, event handling, immutable state updates.

- [Redux Toolkit Quick Start](https://redux-toolkit.js.org/tutorials/quick-start)
  Official RTK guide. Covers configureStore, createSlice, useSelector, useDispatch. Use for: modern Redux pattern from scratch.

- [Redux Essentials Tutorial](https://redux.js.org/tutorials/essentials/part-1-overview-concepts)
  Full end-to-end walkthrough — async thunks, loading state, error handling. Use for: building real async Redux flows.

- [Why Redux Toolkit is the standard way to write Redux](https://redux.js.org/introduction/why-rtk-is-redux-today)
  Explains why plain Redux (manual action types, switch reducers) was replaced by RTK. Use for: interview talking points about RTK vs old Redux.

## Wisdom (Communities)

- [r/reactjs](https://reddit.com/r/reactjs)
  High-signal, well-moderated. Use for: real-world patterns, common pitfalls, architectural discussions.

- [Reactiflux Discord](https://www.reactiflux.com/)
  The largest React community. Direct access to library authors and senior engineers. Use for: quick architecture questions.
