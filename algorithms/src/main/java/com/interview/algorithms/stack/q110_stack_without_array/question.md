# q110 — Stack Without Array

**Category:** Algorithms | **Difficulty:** Easy | **Ideal time:** 15 min

---

## Problem

Implement a stack using a **singly linked list** (no arrays). Support:

- `push(val)` — add to top O(1)
- `pop()` — remove from top O(1), throws if empty
- `peek()` — read top value O(1), throws if empty
- `isEmpty()` — O(1)
- `size()` — O(1)

---

## Example

```java
stack.push(1); stack.push(2); stack.push(3);
stack.peek()   → 3
stack.pop()    → 3
stack.pop()    → 2
stack.size()   → 1
stack.isEmpty() → false
```
