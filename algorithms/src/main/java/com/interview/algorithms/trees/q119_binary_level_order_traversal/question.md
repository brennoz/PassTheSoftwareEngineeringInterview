# q119 — Binary Tree Level Order Traversal

**Category:** Algorithms | **Difficulty:** Medium | **Ideal time:** 20 min

---

## Problem

Given the root of a binary tree, return the level order traversal of its nodes' values (i.e., from left to right, level by level) as a `List<List<Integer>>`.

---

## Examples

```
Input:  [3,9,20,null,null,15,7]   Output: [[3],[9,20],[15,7]]
Input:  [1]                        Output: [[1]]
Input:  []                         Output: []
```

---

## Constraints

- Number of nodes: 0 to 2000
- -1000 <= Node.val <= 1000
