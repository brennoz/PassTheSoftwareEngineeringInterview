# q113 — Max Depth of Binary Tree

**Category:** Algorithms | **Difficulty:** Easy | **Ideal time:** 15 min

---

## Problem

Given the root of a binary tree, return its maximum depth.

The maximum depth is the number of nodes along the longest path from the root node down to the farthest leaf node.

---

## Examples

```
Input:  [3,9,20,null,null,15,7]   Output: 3
Input:  [1,null,2]                Output: 2
```

---

## Constraints

- Number of nodes: 0 to 10⁴
- -100 <= Node.val <= 100

---

## Your task

Edit `MyAnswer.java` — implement both `maxDepth(TreeNode root)` (recursive) and `maxDepthIterative(TreeNode root)` (iterative using a stack).
The `TreeNode` and `Pair` inner classes are provided.
Write tests in `MyAnswerTest.java` (TDD encouraged).
