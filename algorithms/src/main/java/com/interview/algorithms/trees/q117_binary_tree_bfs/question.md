# q117 — Binary Tree BFS

**Category:** Algorithms | **Difficulty:** Easy | **Ideal time:** 15 min

---

## Problem

Given the root of a binary tree, implement two BFS traversals:

1. `bfsFlat(TreeNode root)` — return all node values in BFS order as a flat list.
2. `bfsByLevel(TreeNode root)` — return node values grouped by level as a list of lists.

---

## Examples

```
Input:  [3,9,20,null,null,15,7]
bfsFlat:    [3, 9, 20, 15, 7]
bfsByLevel: [[3], [9, 20], [15, 7]]
```

---

## Constraints

- Number of nodes: 0 to 2000
- -1000 <= Node.val <= 1000

---

## Your task

Edit `MyAnswer.java` — implement both `bfsFlat` and `bfsByLevel`.
Write tests in `MyAnswerTest.java` (TDD encouraged).

Say `hint` if stuck. Say `done` when finished.
