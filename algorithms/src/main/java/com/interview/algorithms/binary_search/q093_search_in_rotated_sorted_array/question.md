# q093 — Search in Rotated Sorted Array

**Category:** Algorithms | **Difficulty:** Medium | **Ideal time:** 20 min

---

## Problem

You are given an array of unique integers `nums` sorted in ascending order, then rotated between 1 and n times. Given an integer `target`, return the index of `target` within `nums`, or `-1` if not present.

**You must write an algorithm that runs in O(log n) time.**

---

## Examples

```
Input:  nums=[3,4,5,6,1,2], target=1   Output: 4
Input:  nums=[3,5,6,0,1,2], target=4   Output: -1
```

---

## Constraints

- 1 <= nums.length <= 5000
- -10,000 <= nums[i], target <= 10,000
- All elements are unique.

## Recommended complexity

O(log n) time.
