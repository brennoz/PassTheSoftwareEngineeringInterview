# q101 — Reverse Linked List

**Category:** Algorithms | **Difficulty:** Easy | **Ideal time:** 15 min

---

## Problem

Given the beginning of a singly linked list `head`, reverse the list and return the new head.

---

## Examples

```
Input:  [0,1,2,3]   Output: [3,2,1,0]
Input:  []          Output: []
```

---

## Constraints

- 0 <= list length <= 1000
- -1000 <= Node.val <= 1000
