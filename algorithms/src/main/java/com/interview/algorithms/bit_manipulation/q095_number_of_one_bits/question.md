# q095 — Number of One Bits

**Category:** Algorithms | **Difficulty:** Easy | **Ideal time:** 10 min

---

## Problem

You are given an unsigned 32-bit integer `n`. Return the number of `1` bits in its binary representation (also known as the Hamming weight).

---

## Examples

```
Input:  n = 00000000000000000000000000010111   Output: 4
Input:  n = 01111111111111111111111111111101   Output: 30
```

---

## Constraints

- `n` is a non-negative integer that fits within 32 bits.
