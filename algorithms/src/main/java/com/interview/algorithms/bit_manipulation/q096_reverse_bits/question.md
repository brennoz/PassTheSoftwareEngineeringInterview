**Category:** Algorithms | **Difficulty:** Easy | **Ideal time:** 10 min

## Problem

---

## Examples

```
Input:  n = 00000000000000000000000000010101  (decimal 21)
Output: 2818572288  (10101000000000000000000000000000)
```

---

## Constraints

- `n` is a non-negative 32-bit integer.
