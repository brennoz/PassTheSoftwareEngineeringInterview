# q090 — Longest Repeated Character Substring

**Category:** Algorithms | **Difficulty:** Medium | **Ideal time:** 15 min

---

## Problem

Given a string `s`, find and return the **longest substring** made up of the same character repeated consecutively.

If there are multiple substrings with the same maximum length, return the **first one** (smallest starting index).

---

## Examples

```
Input:  "aaabbccccd"   Output: "cccc"
Input:  "abcde"        Output: "a"
Input:  "aabbbbccaa"   Output: "bbbb"
Input:  ""             Output: ""
```

---

## Constraints

- Scan the string in a single pass (one loop, no nested loops).
- O(n) time.
