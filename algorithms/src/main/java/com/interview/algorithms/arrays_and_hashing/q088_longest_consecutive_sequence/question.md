# q088 — Longest Consecutive Sequence

**Category:** Algorithms | **Difficulty:** Medium | **Ideal time:** 20 min

---

## Problem

Given an array of integers `nums`, return the length of the longest consecutive sequence of elements.

A consecutive sequence is one where each element is exactly 1 greater than the previous. Elements do not need to be adjacent in the original array.

**You must solve it in O(n) time.**

---

## Examples

```
Input:  [2, 20, 4, 10, 3, 4, 5]   Output: 4   (sequence: 2,3,4,5)
Input:  [0, 3, 2, 5, 4, 6, 1, 1]  Output: 7   (sequence: 0,1,2,3,4,5,6)
```

---

## Constraints

- 0 <= nums.length <= 1000
- -10^9 <= nums[i] <= 10^9

## Recommended complexity

O(n) time, O(n) space.
