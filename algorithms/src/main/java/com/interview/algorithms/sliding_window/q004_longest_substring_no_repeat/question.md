# Q004 — Longest Substring Without Repeating Characters

**Category:** Algorithms  
**Difficulty:** Medium  
**Ideal Time:** 20 min

---

## Problem

Given a string `s`, return the length of the longest substring without repeating characters.

---

## Examples

```
Input:  "abcabcbb"  → 3   ("abc")
Input:  "bbbbb"     → 1   ("b")
Input:  "pwwkew"    → 3   ("wke")
Input:  ""          → 0
Input:  " "         → 1
Input:  "au"        → 2
```

---

## Constraints

- `0 <= s.length <= 5 * 10^4`
- `s` consists of English letters, digits, symbols, and spaces

---

## What to Implement

```java
public int lengthOfLongestSubstring(String s)
```
